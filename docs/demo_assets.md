## 🎨 Asset Style & Theme Guidelines

1. **Resolution & Format:**
   - Vector graphics (SVG) or high-density PNG (minimum 1920 × 1080 for wide diagrams, 1200 × 900 for square plots).
2. **Typography & Styling:**
   - Sans-serif font (Inter, Roboto, or system sans-serif) for chart labels.
   - Clean dark or high-contrast modern light background matching GitHub standard dark/light themes.
3. **Medical Visualization Authenticity:**
   - Maintain accurate clinical aspect ratios on radiograph previews.
   - All metric labels must state exact sample counts ($N = 4,003$ test patients) and threshold values.
